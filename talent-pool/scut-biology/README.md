# 华南理工大学 生物科学与工程学院 · 人才库

把学院官网 [师资队伍](https://www2.scut.edu.cn/biology/jsdw/list.htm) 上的 **教授 / 副教授 / 研究员** 的简历、代表论文、专利，
结合互联网公开资料，整理成可检索、可筛选、带标签的结构化人才库。

## 目录
- `faculty.json` —— 全部人员结构化档案（每人一对象：职称/邮箱/办公室/官方研究方向/简历/代表论文/专利/四维标签/来源/置信度/在岗状态）
- `faculty.csv` —— 扁平总表，方便在 Excel/表格里按标签、产业转化潜力、合作可对接性筛选排序
- `_parts/` —— 采集分片：
  - `official_roster.json` —— **学院官网师资页(2026)权威名单**（职称/邮箱/办公室/官方研究方向），由用户提供，作为职称与在岗判定的权威来源
  - `part_*.json` —— 按姓氏分桶的检索数据分片
  - `merge.py` —— 合并脚本：用官方名单覆盖职称、补邮箱/办公室、标注在岗状态，重跑即可重建上面两个文件

## 规模
- **现任 44 人**：教授 30、副教授 14（与官网师资页一致）。
- 另有 **12 人**在早期检索中被纳入、但**不在 2026 现任师资页(教授/副教授)名单**，已保留并标注 `roster_status`（见下）。
- 总记录 56 条。

## 四个标签维度（对应你的需求）
1. **研究方向 / 技术领域**（`research_official` 官方方向 + `tags.research_field` + `research_areas` 检索细分）。
2. **人才头衔 / 层级**（`title` + `talent_titles` + `tags.seniority`）：职称，以及 国家杰青 / 国家优青 / 长江学者 / 三级教授 / 海外高层次人才 / 省杰青 等。
3. **产业转化潜力**（`tags.industry_potential`，高/中/低 + 理由）：方向应用性 + 是否有专利 + 是否有产业化/中试/校企合作记录。
4. **合作 / 可对接性**（`tags.collaboration`，高/中/低 + 理由）：方向应用属性、团队与平台、是否招生招博后、国际/横向合作活跃度。

## 数据来源分层（务必先读）
- **职称 / 邮箱 / 办公室 / 官方研究方向**：来自**学院官网师资页**（用户提供的权威名单），可信。
- **简历 / 代表论文 / 专利 / 引用指标 / 标签**：来自**搜索引擎摘要 + 第三方公开镜像**（X-MOL、百度学术、ResearchGate、Google Patents、PubMed、研招专家库等）。原因：官网 `www2.scut.edu.cn` 对抓取工具一律返回 **403**，沙箱网络白名单也未放行该域名，**无法直接抓取官网 HTML**。
- 因此引用数 / h 指数 / 完整论文与专利清单**普遍不全**，查不到一律留空，**未编造任何数字**。每条记录带 `confidence` 与 `sources`；仅有官方基础信息、检索数据待补的，带 `data_caveat`。
- 同名混淆条目（多个 Lixin Luo / Wei Chen / Yi Zhang 等）已主动剔除。

### `roster_status` 字段含义
- `现任(官网师资页2026)` —— 在最新官方名单中。
- `未在现任师资页…待核实` —— 早期检索纳入但不在最新官方名单，可能属研究员序列单列、已退休/调离或院系调整。例：`林章凛`（已确认 2022 起主要任职中科院深圳先进院）、`杜宇辉`（副研究员，官方页只列教授/副教授）等。**保留数据但不当作现任。**

## 重建数据
```bash
cd talent-pool/scut-biology/_parts
python3 merge.py   # 读取 official_roster.json + part_*.json → 生成 ../faculty.json 与 ../faculty.csv
```
