# 华南理工大学 生物科学与工程学院 · 人才库

把学院官网 [师资队伍](https://www2.scut.edu.cn/biology/jsdw/list.htm) 上的 **教授 / 副教授 / 研究员** 的简历、代表论文、专利，
结合互联网公开资料，整理成可检索、可筛选、带标签的结构化人才库。

## 目录
- `faculty.json` —— 全部人员结构化档案（每人一个对象，含简历/方向/代表论文/专利/标签/来源/置信度）
- `faculty.csv` —— 扁平总表，方便在 Excel/表格里按标签、产业转化潜力、合作可对接性筛选排序
- `_parts/` —— 按姓氏分桶采集的原始分片与合并脚本 `merge.py`（重跑即可重建上面两个文件）

## 四个标签维度（对应你的需求）
1. **研究方向 / 技术领域**（`tags.research_field` + `research_areas`）：如 发酵工程 / 酶工程 / 合成生物学 / 代谢工程 / 生物制造 / 生物制药 / 药物化学 / 生物材料 / 微生物生态·环境生物 / 生物力学 / 结构生物学 / 神经科学 等。
2. **人才头衔 / 层级**（`title` + `talent_titles` + `tags.seniority`）：职称，以及 国家杰青 / 国家优青 / 长江学者 / 三级教授 / 海外高层次人才 / 省杰青 等称号。
3. **产业转化潜力**（`tags.industry_potential`，高/中/低 + 理由）：方向应用性 + 是否有专利 + 是否有产业化/中试/校企合作记录。
4. **合作 / 可对接性**（`tags.collaboration`，高/中/低 + 理由）：方向应用属性、团队与平台、是否招生招博后、国际/横向合作活跃度。

## ⚠️ 数据来源与可信度（务必先读）
- 学院官网（`www2.scut.edu.cn`）对抓取工具一律返回 **403**，沙箱网络白名单也未放行该域名，因此**无法直接抓取官网 HTML**。本库全部数据来自**搜索引擎摘要**（WebSearch）+ 第三方公开镜像（X-MOL、百度学术、ResearchGate、Google Patents、PubMed、期刊页、研招专家库 yanzhao.scut.edu.cn 等）。
- 同理，Google Scholar / 专利库等页面对抓取工具也多为 403，**引用数 / h 指数 / 完整论文与专利清单普遍缺失或不完整**，能查到的才填，查不到一律留空，**未编造任何数字**。
- 每条记录带 `confidence`（high/medium/low）与 `sources`；个别重名风险大或官网个人页未检索到的（如 `陈巍`、`陈泽虹`）带 `data_caveat` 字段说明。
- `representative_papers` / `patents` 仅收录**能与本人对应上**的条目；同名混淆的（如多个 Lixin Luo / Wei Chen / Yi Zhang）已主动剔除并在子代理记录中说明。
