【ODFanalyse 评估：一水肌酸 Creatine monohydrate】  语境：补剂(supplement)

一、查证数据（带来源）
- **MW / logP / pKa**：无水肌酸 MW 131.13（CID 586）/ 一水合物 149.15；XLogP3 = **-1.2**（强亲水，穿不过磷脂双层）；pKa 羧基 ~2.67、胍基 ~11.02 → 口腔/生理 pH 下为**两性离子**(净电中性但两端带电)，被动跨膜极差；水溶解度约 13 g/L(20°C)。〔PubChem CID 586/80116〕
- **口服 BA% 及机制**：剂量依赖——低剂量约 **53%**，高剂量仅约 **16%**（Persky 2003 人体 PK）；下降主因是**溶解度 / 肌酸转运体 CRT1 饱和**，属**渗透/饱和型**而非首过型。Tmax 约 1-2 h。→ 舌下绕过首过没有价值，**救不动**。〔Persky 2003；PMC5874844〕
- **有效剂量**：维持 **3-5 g/天**，负荷期 **20 g/天**(4×5g)。远超单膜 API 上限(~10-50mg，纪录 62.5mg)。→ **触剂量一票否决**。〔ISSN position stand；Healthline〕
- **口感 / 稳定性**：近乎无味、微涩，掩味不难、无需包埋——但克级载药本身物理不可行，E 的"工艺友好"在这里毫无意义。
- **市场 / 合规**：巨型品类(ON/Naked/Nutricost/Sports Research)，但**清一色粉/胶囊/软糖，无口溶膜竞品**——正因为克级剂量装不进膜。DSHEA 下合法，Creapure 一水肌酸 **GRAS(GRN 931)**，无监管红线，TikTok 不限流。〔FDA GRN 931；Amazon〕

三、产品评估
- **卖点该押什么**：无可押。膜剂连一次有效剂量(3-5g)都装不进，撕膜 ASMR / 无水便携都救不了"剂量装不下"这个物理事实。即便做成膜，用户也得撕几十张才够一勺粉——非产品。
- **第2层商业体检**：不进入(总分 < 70)。横向对标上，粉剂/胶囊/软糖在单位经济和剂量灵活性上完全碾压膜剂，肌酸膜没有任何剂型不可替代性。
- **风险红线**：命中**剂量一票否决**(单次有效剂量 g 级 ≫ 100mg，单膜物理不可行)，D=0，总分封顶 ≤40。其余维度(A 渗透型救不动、B 饱和型非首过、C 纯慢性肌肉饱和需 3-4 周)亦不支持舌下逻辑。监管/口感均无额外红线，但不改变结论。
- **一句话结论**：理化勉强(小分子但强亲水两性离子)，真正死因是有效剂量 3-5g 远超单膜上限——**剂量否决型，膜剂物理不可行，直接 Pass**（命中校准锚点 29 分）。
