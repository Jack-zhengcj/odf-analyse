【ODFanalyse 评估：酸樱桃 Tart cherry (Prunus cerasus)】  语境：补剂（美国 TikTok DTC 开品）

## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 全食物水果浓缩物/混合物,无单一 MW；标志活性花青素如 cyanidin-3-glucoside ≈449 Da、cyanidin-3-rutinoside ≈595 Da(>多糖苷)；另含微量褪黑素(MW232)、酚酸、纤维/糖 |
| logP/logD | 花青素亲水(糖苷化、多酚羟基+苷键)，logP 低、强极性；中性 pH 下花青素显色态/醌式带电、稳定性差 |
| pKa/解离 | 花青素阳离子(flavylium)随 pH 变构:酸性带正电稳定、口腔/血液近中性 pH 转为半缩酮/醌式(不稳定、易降解)；酚羟基 pKa~8–10 |
| 口服绝对BA% | 花青素口服 BA 极低——经典示踪研究多 <1% 原型回收；近年 ¹³C 示踪相对 BA 约 12%(含代谢物/呼出)，但原型花青素入血极微,大量经结肠菌群代谢为酚酸；微量褪黑素剂量(每份 ng–低µg 级)亦不足药理量 |
| BA低/高的机制(首过 vs 渗透) | 渗透/溶解度型(伪需求)+作用经代谢物/慢性:抗氧化抗炎/助眠效应主要靠肠道代谢产物与微量褪黑素的累积,原型花青素既透不过黏膜(糖苷化大极性分子、中性 pH 降解)又非血药直达;舌下绕首过救不动一团亲水多酚,也无 g 级载量 → A/B 低 |
| 有效剂量 mg | 恢复/睡眠人体试验用浓缩液 30–60mL(≈90–120 颗樱桃当量)或胶囊/粉 480mg–1g+/次,提供花青素 55–720mg/日；浓缩物/全果粉为 g 级,远超单膜 ≤100mg → 载药 D=0,dose 一票否决封顶40 |
| 舌下/口腔黏膜人体证据 | 无任何人体舌下/buccal PK；g 级浓缩物/全果粉无法成舌下膜;花青素中性 pH 不稳定,口腔停留即降解 |
| 水溶解度 | 花青素水溶但中性唾液 pH 下变构降解、显色/活性丢失 |
| 口感/稳定性 | 酸樱桃强酸+涩(单宁/多酚),但属食物风味、可调味掩盖,中等(E=5) |
| 市场/竞品 | 运动恢复/助眠/抗炎食品赛道(Montmorency 浓缩、CherryPURE 等),叙事温和;关键优势——属食物水果非草本/非激素/非减肥,不踩 TikTok 红线;但同质化、低价果汁/软糖竞争、卖点难差异化 → F 中(9) |
| 合规 | 食品级、DSHEA 合规无虞;'舌下=新摄入途径'理论可触 NDIN 但风险低 |

## 三、产品评估

**六维打分依据**：A=4：标志活性是花青素(cyanidin-3-glucoside~449、糖苷化大极性多酚)+微量褪黑素的全食物混合物,花青素强亲水带糖苷、中性唾液 pH 变构降解,被动透黏膜极差→低。B=6：渗透/溶解度型伪需求——助眠/抗炎靠肠道代谢物(酚酸)与微量褪黑素累积,原型花青素口服 BA<1–12%、几乎不入血更透不过黏膜,舌下绕首过既救不动也无救必要。C=5：恢复/睡眠是半急性—慢性(连服数日见效、非单次药理即感),偏低。D=0：有效剂量为 g 级浓缩物/全果粉(花青素 55–720mg/日伴大量糖/纤维基质),单膜 ≤100mg 装不下,dose 一票否决封顶40。E=5：酸涩但属食物风味可掩,中等。F=9：属食物水果——非草本/非激素/非减肥,不踩 TikTok 红线(优于姜黄/醉茄等草本),但赛道同质化+低价竞争,中。kill=dose cap40,实得 29。

**结论**：酸樱桃是 g 级全食物浓缩物,助眠/恢复靠微量褪黑素+肠道酚酸代谢物累积,原型花青素 BA<1–12% 透不过黏膜也无救必要;剂量 g 级装不进膜→剂量否决;胜在属食物不踩 TikTok 红线 → 29 🔴 直接Pass。
