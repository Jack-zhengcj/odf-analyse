【ODFanalyse 评估：维生素C 抗坏血酸 Vitamin C】  语境：补剂(supplement)

一、查证数据（带来源）
- **MW / logP / pKa**：MW **176.12**（L-抗坏血酸 C6H8O6，PubChem）；XLogP3 ≈ **-1.6**（强亲水，穿不过磷脂双层）；pKa1 **4.17** / pKa2 11.6 → 口腔 pH≈6.5 下第一个羟基已解离为**抗坏血酸根阴离子(带负电)**，被动跨膜极差；水溶解度极高(~300 g/L)。小分子(MW 176)本不该是障碍，但**强亲水 + 带电**把 A 压低。〔PubChem；ChemicalBook 50-81-7〕
- **口服 BA% 及机制**：剂量依赖——低/中剂量(30-200mg)绝对 BA **≈ 80-90%**（已很高，无提升空间）；>1000mg 分数吸收骤降至 **<50%**，主因是肠道 **SVCT1 转运体饱和**（一级→零级动力学），属**饱和/渗透型**而非首过型。Tmax 约 2-3 h，非急性成分。→ 舌下绕过首过**没有价值**，高剂量饱和**救不动**。〔MDPI Pharmaceutics 2025；MDPI Nutrients 11(10):2412；PMC12655283〕
- **有效剂量**：市售常规单次 **500-1000mg**（免疫/胶原）。远超单膜 API 上限(~10-50mg，纪录 62.5mg)。→ **触剂量一票否决**。RDA 仅 75-90mg，但市场剂量普遍克级；200mg 即近血浆饱和，UL 2000mg/天。〔NIH ODS；Amazon 市售标签〕
- **口感 / 稳定性**：明显**酸味**(可调味掩盖)，但**易氧化**(→脱氢抗坏血酸)，含水成膜稳定性是扣分项，需适度保护——但克级载药本身物理不可行，E 的"工艺友好"在此毫无意义。
- **市场 / 合规**：超大成熟品类(NOW/Nature Made/Emergen-C/Ester-C)，**清一色片/泡腾/粉/软糖，无主流口溶膜竞品**——正因克级剂量装不进单膜。红海无剂型不可替代性。DSHEA 下合法、GRAS、无监管红线、TikTok 不限流。〔FDA DSHEA；Amazon〕

三、产品评估
- **卖点该押什么**：无可押。膜剂连一次有效剂量(500-1000mg)都装不进，撕膜 ASMR / 无水便携救不了"剂量装不下"这一物理事实。即便硬做成膜，也得撕十几张才够一片 1000mg 泡腾片——非产品。
- **第2层商业体检**：不进入(总分 < 70)。横向对标上，泡腾/咀嚼片/软糖/粉在单位经济与剂量灵活性上完全碾压膜剂，维C膜无任何剂型不可替代性。
- **风险红线**：命中**剂量一票否决**(单次 500-1000mg ≫ 100mg，单膜物理不可行)，D=0，总分封顶 ≤40。其余维度(A 强亲水带电阴离子渗透差、B 低剂量 BA 已 80-90% 无提升+高剂量 SVCT1 饱和救不动、C 纯慢性免疫/胶原无即时体感)亦不支持舌下逻辑。监管/口感无额外红线，但不改变结论。
- **一句话结论**：理化(小分子但强亲水抗坏血酸根阴离子)勉强，BA 端两头堵死(低剂量已满无空间、高剂量饱和救不动)，真正死因是市售有效剂量 500-1000mg 远超单膜上限——**剂量否决型，膜剂物理不可行，直接 Pass**（与肌酸 29 同属剂量否决低区，A 更差故 26 分）。
