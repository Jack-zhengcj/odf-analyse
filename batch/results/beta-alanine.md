## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 89.09 g/mol（C3H7NO2，PubChem CID 239；最小的 β-氨基酸） |
| logP/logD | XLogP3 ≈ -3.0（强亲水，被动跨膜差） |
| pKa/解离 | 羧基 ~3.6 / 氨基 ~10.2 → 口腔/生理 pH 下为两性离子(zwitterion)，被动渗透差 |
| 水溶解度 | 水溶性高；MW 虽极小但全程离子化，跨膜依赖 β-氨基酸/牛磺酸转运体(TauT/PAT1)非被动扩散 |
| 口服绝对BA% | 口服吸收快但血浆半衰期极短(~25 min)、迅速被肌肉 TauT 转运体摄取；缓释剂型可把 paresthesia 由 55-70% 降到 ~10-12% 并提升『净』利用——本质是平滑峰值而非提升黏膜吸收 |
| BA低/高的机制(首过 vs 渗透) | 渗透/转运体型，非首过型。β-丙氨酸不经显著肝首过，低『有效性』来自转运体饱和+快速清除+肌肉慢积累(肌肽合成限速)；强亲水离子分子被动透膜差 → 舌下绕过首过无意义，救不动 extent |
| Tmax/起效 | 口服约 30-45 min（血浆峰，随后快速下降） |
| 有效剂量 mg | 常规有效单次 0.8-1.6 g（避刺痛分次），日总 3.2-6.4 g，疗程 4-12 周累积肌肽 → 单次即超 100mg，触剂量一票否决 |
| 舌下/口腔黏膜人体证据 | 无舌下/buccal 人体 PK；市售克级粉/胶囊(pre-workout)，无口溶膜竞品；缓释/包合(Hydro-Oleo、缓释片)研究均针对降刺痛而非黏膜吸收 |
| 口感/稳定性 | 近乎无味/微涩，掩味不难，但克级载药物理不可行 |
| 市场/竞品 | pre-workout 耐力/缓冲主力(常与瓜氨酸/肌酸复配)；标志性『刺痛 paresthesia』(MrgprD 介导，10-20min 起、60-90min 消)是天然体感钩子，可拍但属慢性积累功效 |
| 合规 | DSHEA 下合法；非红线品类；TikTok 不直接限流 |

## 三、产品评估

**结论**：MW 极小但强亲水两性离子+转运体依赖(舌下救不动)，且单次 0.8-1.6g、日 3.2-6.4g(剂量否决)——刺痛体感是唯一亮点(C 半急性)，但封顶 ≤40，直接 Pass。
