【ODFanalyse 评估：角蛋白 Keratin】  语境：补剂（美国 TikTok DTC 开品）

## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 天然角蛋白为大分子结构蛋白(数万~十万 Da，富含半胱氨酸二硫键，根本不能被同化)；水解角蛋白 MW 500-10,000 Da，仍 >800；可溶化品牌(Cynatine HNS)主打『低分子三肽』但仍是肽混合物 |
| logP/logD | 亲水多肽/蛋白(大量极性与可解离侧链、二硫键)，强亲水、无固定 logP |
| pKa/解离 | 多肽两性(N端氨基/C端羧基+酸碱性侧链)，整体两性、带电 |
| 口服绝对BA% | 原态角蛋白口服基本不吸收(大分子结构蛋白)；水解/可溶化形式经肠道肽酶切为小肽/氨基酸吸收，再供给毛发指甲角蛋白合成——属间接机制，非原蛋白入血起效 |
| BA低/高的机制(首过 vs 渗透) | 渗透型 + 间接机制(概念错配)：作用靠消化道把大分子角蛋白/肽切成氨基酸再合成新角蛋白(美容慢效)，并非原分子透膜入血；MW≥数千~数万的蛋白/肽透不过黏膜，舌下既绕不过『需先消化水解』也救不动大分子→A/B 低 |
| 有效剂量 mg | 品牌可溶化角蛋白(Cynatine HNS)有效量 500 mg/日(临床 3 个月);普通水解角蛋白粉常 500 mg~1 g+ → 单次有效量已 >100mg，触 dose 一票否决，D=0 cap40 |
| 舌下/口腔黏膜人体证据 | 无任何人体舌下/buccal 角蛋白 PK；厂商仅宣称『低分子高生物利用度』但指口服肠道吸收，非舌下；500mg+ 也无法做成舌下膜 |
| 口感/稳定性 | 水解角蛋白(常羽毛/羊毛源)有蛋白腥/微苦，可香精掩味，中等 E=5 |
| 市场/竞品 | 美容『头发-皮肤-指甲(HNS)』赛道大，可搭便车，但同质化、与胶原/生物素重叠；非 TikTok 红线(非美白/非疾病/非激素)，但大分子蛋白粉+>100mg 不适合膜剂，给 F=5 |

**来源**：https://pmc.ncbi.nlm.nih.gov/articles/PMC4214097/ (Cynatine HNS 角蛋白 500mg/日 × 3月 RCT，发/甲参数)；https://www.biocyte.com/en/blogs/news/keratin-natural-hair-protein (天然角蛋白大分子不可同化，需水解为肽；水解 MW 500-10,000 Da)；https://lyma.life/en-us/pages/cynatine (可溶化角蛋白主打低分子三肽口服吸收，剂量 500mg)

**置信度**：高：天然角蛋白大分子/水解品 MW 500-10,000Da(>800)、有效量 500mg~1g+(>100mg)、起效经消化成氨基酸再合成发甲的间接机制均有文献支撑；dose 一票否决与各维拆分确定。PubChem 因蛋白混合物无单一 CID，理化按蛋白/肽通性判定。

## 三、产品评估

**六维打分依据**：A=2：天然角蛋白大分子结构蛋白(数万 Da)、水解品仍 500-10,000 Da(>800)、强亲水带电，黏膜被动透不过→极低。B=3：渗透型+间接机制(概念错配)，起效靠肠道肽酶把蛋白/大肽切成氨基酸再合成新角蛋白(美容慢效)，原分子不入血、舌下救不动大分子。C=3：美容慢性积累(发甲改善需~3个月)，非急性即感。D=0：可溶化品牌 500mg/日、普通粉 500mg~1g+，单次有效量已 >100mg，dose 一票否决封顶40。E=5：羽毛/羊毛源蛋白腥味需香精掩味，中等。F=5：HNS 美容赛道大可搭便车但同质化(与胶原/生物素重叠)、非红线，给中低。kill=dose cap40，实得 18。

**结论**：角蛋白是大分子结构蛋白(水解品仍>800)、起效靠消化成氨基酸再合成发甲(间接慢效)、有效量 500mg+ 装不进膜 → dose 一票否决 18 🔴。
