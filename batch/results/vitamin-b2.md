【ODFanalyse 评估：维生素B2 核黄素 Riboflavin】  语境：补剂(supplement)

一、查证数据（带来源）
- **MW / logP / pKa**：MW **376.36**（C17H20N4O6，CID 493570）；XLogP3 ≈ **-1.5**（PubChem）/ logP 估算 **-2.0**（ChemicalBook）→ **强亲水**，穿不过磷脂双层；强酸性 pKa ≈ **1.7**（酰亚胺 N-H），口腔 pH 下主体中性但黄素三环高度极性/强氢键；水溶性**极差** ≈ **0.07–0.12 g/L**(20°C)，practically insoluble——连 ~1 mL 唾液都难溶出足量游离药物。〔PubChem；ChemicalBook 83-88-5〕
- **口服 BA% 及机制**：经 **RFVT1/RFVT3 主动转运**吸收，**剂量依赖且饱和**——单次最大可吸收量约 **27 mg 封顶**，超出部分基本不吸收。属【**饱和/转运体上限型**】，**非首过型**。Tmax ≈ 1.4–2 h。→ 舌下不提供新转运体、同样撞被动渗透墙，**救不动**（onset 与 extent 均无提升）。〔NBK114322；Levy 1966 J Pharm Sci；Jusko/Levy AJCN〕
- **有效剂量**：RDA **1.1–1.3 mg/天**；常规补剂 25–100 mg；头牌临床用途**偏头痛预防 400 mg/天**（Schoenen Neurology 1998；AAN/AHS **Level B**，需连服 1–3 月才评效）。→ 远超单膜 API 上限(~10–50mg，纪录 62.5mg)，**触剂量一票否决**。〔Neurology 1998；PMC3952759〕
- **口感 / 稳定性**：微苦可掩，但**强黄–橙色、染色强**；**光敏**（紫外/可见光下降解为 lumichrome），需避光成膜与避光包装；水溶性极差进一步抬高成膜/溶出难度。
- **市场 / 合规**：**无独立 B2 口溶膜竞品**，仅复合维生素膜（DISO M-VIT 等）含微量 B2；胶囊/片剂（Nutricost / Micro Ingredients 400mg）主导、廉价大宗，剂型无不可替代性；慢性保养、无急性体感、无 ASMR 急性钩子。DSHEA 下合法，无监管红线，TikTok 不限流（但功效慢、不可视频化）。〔Amazon；FDA DSHEA〕

三、产品评估
- **卖点该押什么**：无可押。BA 低≠舌下值钱——核黄素低 BA 是 **RFVT 转运体在 ~27mg 饱和**（饱和/渗透型），不是首过代谢，舌下绕不过、也补不上转运体，押"更好吸收"是伪命题。强亲水+水溶性极差让舌下被动渗透雪上加霜。撕膜便携也救不了"剂量装不下 + 慢性无体感"。
- **第2层商业体检**：不进入（总分 < 70）。横向对标上 400mg 胶囊 / 片剂在单位经济与剂量上完全碾压膜剂；B2 膜没有任何剂型不可替代性，且强染色是货架/口腔染黄的负资产。
- **风险红线**：命中**剂量一票否决**——头牌有效剂量（偏头痛 400mg）≫ 100mg，单膜物理装不下，D=0、总分封顶 ≤40。次级问题：A 强亲水+难溶（舌下吸不进）、B 饱和型非首过（救不动）、C 纯慢性（偏头痛预防需 1–3 月起效，能量代谢日常维持，无急性体感）、E 强黄染色+光敏增加工艺/稳定性成本。
- **一句话结论**：水溶性差的强亲水 B 族，饱和吸收（~27mg 上限）证明技术分不该虚高；理化与机制双弱，再加头牌剂量 400mg 远超单膜上限——**剂量否决型，舌下/口溶膜不成立，直接 Pass**（tech 19，与肌酸 29 同档偏低，远低于 B12甲钴胺 46）。
