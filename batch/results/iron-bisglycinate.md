## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 约 321 g/mol（Fe(II) + 2×甘氨酸螯合, C4H8FeN2O4），含 ~20% 元素铁 |
| logP/logD | 不适用/极低——核心为 Fe2+ 螯合物（带电过渡金属中心），整体强亲水，被动跨膜差 |
| pKa/解离 | 螯合物，非中性可透膜小分子；甘氨酸两性离子包裹的 Fe2+ 仍属带电/极性 |
| 口服绝对BA% | 较硫酸亚铁高约 2 倍，但绝对值仍低（铁吸收受 DMT1/铁调素 hepcidin 严格稳态调控，缺铁时上调、铁足时下调）；18mg 甘氨酸亚铁≈60mg 硫酸亚铁效果 |
| BA低/高的机制(首过 vs 渗透) | 路线错误/渗透-饱和型：螯合物以「类二肽」完整经肠道转运吸收，受 DMT1+hepcidin 稳态调控，非肝首过；舌下绕过首过无意义，且螯合物透不过口腔黏膜，舌下救不动 |
| 有效剂量 mg | 元素铁 18-65 mg（缺铁治疗 60-120mg 元素铁，预防/孕期 18-30mg）；但盐仅 ~20% 元素铁 → 25mg 元素铁≈125mg 螯合盐，治疗量整盐 300mg+ → 远超 100mg 单膜上限，触剂量一票否决 |
| 舌下/口腔黏膜人体证据 | 无舌下/buccal 人体 PK 证据；无任何上市铁舌下/口腔膜剂——因螯合盐既透不过黏膜又装不进单膜 |
| 口感/稳定性 | 金属/收敛涩味强（铁味），且铁催化氧化、易使制剂变色/产生异味，含水成膜稳定性差，掩味较难 |
| 市场/竞品 | 超大成熟补铁品类(孕期/缺铁)，TikTok 不限流但拥挤；片/胶囊/液体/软糖为主，无口溶膜竞品 |
| 合规 | DSHEA 下合法补充剂，无监管红线；但铁过量(尤其儿童误服)是 FDA 重点警示对象，撕膜剂型安全性存疑 |

## 三、产品评估

**结论**：甘氨酸亚铁是 MW 321 的 Fe2+ 螯合物（带电过渡金属中心、强亲水，A 低）；BA 比硫酸亚铁高 2 倍但仍受 DMT1/hepcidin 稳态调控属路线错误（B 低，非首过、舌下救不动）；真正死因是整盐有效剂量 125-300mg+ 远超单膜 100mg → 剂量否决。技术 22/80、总分 28 🔴 直接 Pass。
