## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 约 45-60 kDa，470 个氨基酸的锌金属蛋白酶(serralysin 家族, 来自 Serratia E-15)；远 >800 渗透死局 |
| logP/logD | 强亲水大蛋白，无固定 logP；被动跨膜不可能 |
| pKa/解离 | 多电荷蛋白，含锌活性中心；整体亲水带电 |
| 口服绝对BA% | 口服肠膜通透性很低(亲水大分子)，需很高剂量口服才见抗炎效应；动物试验确能在血中测到酶，但提升 BA 必须靠肠溶/脂质体/微球等递送术——证据等级仍弱(系统综述指 RCT 质量低、阳性结果有限) |
| BA低/高的机制(首过 vs 渗透) | 渗透型(伪需求)：45-60kDa 蛋白被动透不过黏膜，舌下/口腔膜对大分子完全救不动。低口服『有效性』源于亲水大分子肠膜通透差，正解是肠溶护活性+促渗递送而非舌下；舌下绕不过物理跨膜障碍 → A=2、B=4 |
| 有效剂量 mg | 常规 10-60 mg(标 10000-120000 SPU 酶活单位)，质量克数小、单膜装得下 → D=11(非剂量否决) |
| 舌下/口腔黏膜人体证据 | 无人体舌下/buccal PK；现有制剂全为肠溶片(护活性、肠道释放)，恰说明胃酸/活性保护是核心痛点而非黏膜吸收；活性酶含水成膜常温失活 |
| 口感/稳定性 | 本身味淡，但根障是活性失活(stability)与渗透不可能，非口感 |
| 市场/竞品 | 抗炎/术后消肿/化痰/『溶斑块』概念有受众，但循证薄弱、抗炎/疾病 claim 偏药品红线，平台/合规风险，给中偏低(F=7) |
| 合规 | DSHEA 下作酶补剂存在；抗炎/溶栓类功效宣称偏红线；舌下=新途径理论另议，但本品根障是物理渗透 |

**置信度**：high：MW 45-60kDa(470 aa serralysin 锌金属蛋白酶)、亲水低肠膜通透需高剂量、肠溶片为主流剂型均有来源支撑；渗透死局(MW>>800)+活性酶 stability 双重技术封死确定。绝对口服 BA% 未精确定量、人体证据质量低(标待证)，不改渗透不可能判定。

## 三、产品评估

**六维打分依据**：A=2：45-60kDa 锌金属蛋白酶(470 aa)，远超 800，黏膜被动渗透物理不可能→渗透死局封顶≤50。B=4：渗透型伪需求，亲水大分子肠膜本就透不过，正解是肠溶护活性+促渗递送，舌下绕不过跨膜障碍、救不动大分子。C=5：抗炎/消肿属慢性-半急性，非急性即感。D=11：10-60mg/酶活单位质量小，单膜装得下，非剂量否决。E=3：活性蛋白酶常温含水成膜无法存活(stability)、且需胃酸保护(肠溶)，强制低 E。F=7：抗炎/溶斑块概念有受众但循证薄+疾病 claim 红线，限流/合规风险压分。kill=permeation cap50，实得 32。

**结论**：45-60kDa 锌金属蛋白酶大分子，黏膜透不过(渗透死局)、活性酶需肠溶护活+成膜即失活(stability)、循证薄——舌下救不动，32 🔴。
