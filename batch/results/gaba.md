## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 103.12 |

| 口服绝对BA% | 可经肠吸收入血，但关键纪律：外源 GABA 基本不通过完整血脑屏障——分子较大、带电、极亲水，无法被动跨内皮脂膜；人体证据未显示口服 GABA 可靠提升中枢 GABA |
| BA低/高的机制(首过 vs 渗透) | 路线错误型(B 0-4)：靶点(脑内 GABA 受体)在血脑屏障之内，入血也到不了；任何感知到的放松多为外周(肠-迷走-脑)间接信号而非中枢直达。舌下绕过首过对‘过不了 BBB’这一死结毫无帮助 → B 记 3 |
| 有效剂量 mg | 常规 100-750 mg（部分助眠配方更高）→ 多数落 100-750mg，超单膜上限(此处以路线错误为主因，未以 dose 封顶) |
| 舌下/口腔黏膜人体证据 | 无有效中枢直达的人体舌下 PK；舌下也救不动 BBB |
| 水溶解度 | 水中高度可溶（极亲水） |
| 口感/稳定性 | 中性偏微，可掩 |
| 市场/竞品 | 亚马逊大量 GABA 助眠/抗压补剂，多为概念性宣称；睡眠赛道但机制站不住 |
| 合规 | DSHEA 下合法（日本 FOSHU 有 GABA 食品），无草本/减肥红线；问题是机制非合规 |
