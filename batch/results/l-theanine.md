【ODFanalyse 评估：L-茶氨酸 L-theanine】  语境：补剂（美国 TikTok DTC 开品）

## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 174.2 |
| logP/logD | XLogP3 ≈ -3.6（强亲水，谷氨酰乙胺衍生物） |
| pKa/解离 | 羧 ~2.6 / 氨 ~9.4 → 生理/口腔 pH 下两性离子带电 |
| 口服绝对BA% | 口服 BA 约 70%（空腹>50%）；血清 15 min 达峰，经肠良好吸收并能过血脑屏障 |
| BA低/高的机制(首过 vs 渗透) | 地板/伪需求型(B 7)：小分子能被动+载体透膜，但口服 BA 已不错(~70%)、无肝首过失活缺口可救——舌下既无可救缺口(extent 提不动)，本身又亲水带电透膜效率有限；故 B 落地板 7，非首过型真护城河 |
| 有效剂量 mg | 常规单次 100-200 mg（200 mg 为抗焦虑研究主用量，慢性 200-400 mg/日）→ 单膜上限边缘，落 D 中(5) |
| 舌下/口腔黏膜人体证据 | 无人体舌下/buccal PK 对照；亲水两性离子，舌下主要可能加快 onset(C)而非提升 extent(B) |
| 水溶解度 | 水中高度可溶 |
| 口感/稳定性 | 近无味/微鲜(umami)，掩味不难但需基础包埋(E 中) |
| 市场/竞品 | L-茶氨酸是放松/专注/搭咖啡因抗焦虑热门赛道，亚马逊竞品多；属氨基酸非草本提取，放松/抗压叙事一般不触 TikTok 草本/疾病红线 → F 中(11)，但需自费教育、差异化有限 |
| 合规 | DSHEA 下合法，茶来源氨基酸；无草本/减肥/激素红线 |
