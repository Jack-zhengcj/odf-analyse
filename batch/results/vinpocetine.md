## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 350.5 |
| logP/logD | ~3.3 (XLogP3) |
| pKa/解离 | 弱碱~7.3(吲哚并喹啉氮) |
| 口服绝对BA% | ~7% (口服绝对BA很低，强肝肠首过) |
| BA低/高的机制(首过 vs 渗透) | 首过型：合成长春花生物碱小分子(MW350,logP3.3)本身能透膜，口服BA仅~7%因强首过代谢→理论上舌下能绕过首过救回B，故B给13而非更低；但合规否决使该优势无意义 |
| 有效剂量 mg | 5-40mg单次(常规5-10mg,3次/日)，载药无压力 |
| 舌下/口腔黏膜人体证据 | 无人体舌下/buccal PK对照，舌下吸收为推断 |
| 合规 | FDA 2016-09提出推翻其合法膳食成分地位的初步决定；2019 NTP报告示生殖毒性，FDA发警告称育龄女性服用可致流产/伤胎，并明确『不符合膳食成分定义』→ regulatory一票否决cap45；舌下作为新摄入途径更可能触发NDIN |

## 三、产品评估

**六维打分依据**：A=11：MW350+logP3.3+剂量小，理化本属可舌下的小分子，但logP偏高且无人体PK，给中高而非满。B=13：口服BA~7%是经典首过型缺口，舌下理论真能救(故非伪需求的7-9)，但被合规盖死，不上16+。C=9：益智作用半急性/积累型，非急性即感。D=13：5-40mg轻松装膜。E=7：小分子无需复杂包埋。F=8：FDA已盯+生殖警告，监管阴影下营销受限、无法搭便车。kill=regulatory：FDA认定非合法膳食成分+生殖毒性→cap45，技术分53被封到45。

**结论**：理化上是可舌下的小分子(首过型本可救BA)，但FDA认定其非合法膳食成分+生殖毒性警告→合规一票否决封顶45，剂型再好也不能作补剂卖。
