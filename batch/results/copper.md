## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | Cu²⁺ ≈63.5；常见盐 葡萄糖酸铜 452.8 / 硫酸铜 159.6 |
| logP/logD | 不适用——带 2+ 电荷金属阳离子/无机盐，强亲水，无被动透膜窗口 |
| pKa/解离 | 金属离子，无经典 pKa；生理 pH 下以水合 Cu²⁺/络合形态存在 |
| 口服绝对BA% | BA 随摄入量反向调节：低摄入(0.4mg/d)时~75%、高摄入(7.5mg/d)时降至~12%；生理剂量吸收尚可且受稳态严控 |
| BA低/高的机制(首过 vs 渗透) | 路线错误+稳态地板型——铜经 Ctr1 主动转运入肠上皮、ATP7A 外排，吸收由机体铜稳态严格调控；非肝首过，舌下绕不出任何 AUC，且靶点是 SOD/细胞色素 c 氧化酶等慢性酶辅因子，非血药急性效应 |
| 有效剂量 mg | RDA 0.9 mg/d，UL 10 mg；mg 级以下——载药轻松但极易过量(铜毒/拮抗锌) |
| 舌下/口腔黏膜人体证据 | 无舌下/口腔黏膜 PK 优势证据；2+ 离子无被动透膜需求，舌下=噱头 |
| 口感/稳定性 | 金属涩味/收敛，需掩(可掩，非 krill 级) |
| 市场/竞品 | 铜单补小众，多搭锌/多维；竞品廉价；无独立爆款叙事；非草本/减肥/性功能 → 不直接踩 TikTok 硬红线但赛道弱 |
| 合规 | DSHEA 合法；UL 10 mg，过量致铜毒/拮抗锌吸收/胃肠刺激，需剂量把控；‘舌下新途径’理论上可触 NDIN 但风险低于碘 |

## 三、产品评估

铜是带 2+ 电荷的金属阳离子，经 Ctr1 主动转运吸收且由机体铜稳态严控(BA 随摄入反向调节)，靶点为 SOD/细胞色素 c 氧化酶等慢性酶辅因子——非肝首过、舌下救不出任何 AUC，纯概念错配；剂量 0.9mg 易装但极易过量拮抗锌，技术 30、总分 38🔴 直接 Pass。
