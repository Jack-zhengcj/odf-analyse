【ODFanalyse 评估：南非醉茄 Ashwagandha】  语境：补剂（美国 TikTok DTC 开品）

## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 标志物为一团 withanolides 混合物：withanolide A / withaferin A ≈470.6（C28H38O6）；活性更强的 withanoside 糖苷类 ≈700-780（带糖更大） |
| logP/logD | withaferin A 估 logP≈3-4，但内酯/多羟基结晶；withanolide A 较非极性；糖苷类亲水 |
| pKa/解离 | withanolides 多为中性内酯/羟基（无强解离），糖苷带糖 |
| 口服绝对BA% | crude 提取物口服 BA 低；in vitro Caco-2 渗透差异大——withanolide A Peff 4.05×10⁻⁵ cm/s（较好）但 withaferin A 仅 3.30×10⁻⁷ cm/s（极低，差 100×）；人体 withaferin A Cmax≈124 ng/mL、Tmax≈0.25h；提取物效力高度依赖糖苷含量（WS-35 比 WS-2.5 单位 AUC 高 280 倍） |
| BA低/高的机制(首过 vs 渗透) | 渗透/溶解度型 + 混合物伪需求：产品是 withanolides/withanosides 复杂混合物，关键活性内酯（withaferin A）本身膜渗透极差(3.30e-7)、糖苷类大分子(700+)更透不过；无单一‘干净首过’小分子可被舌下成倍救回 → 舌下 B 低(5)；A 同步低(5) |
| 有效剂量 mg | 标准化提取物 300-600 mg/次（KSM-66/Sensoril，常 1-2 次/日）→ 远超单膜物理装载，载药 D 低(3)；封顶主因 tiktok 非 dose |
| 舌下/口腔黏膜人体证据 | 无任何人体舌下/buccal PK；一团根/叶提取混合物无法定义‘舌下吸收率’；厂商无舌下对照 |
| 水溶解度 | withanolides 亲脂结晶溶出受限，糖苷亲水——混合溶解行为，整体溶出/渗透不利 |
| 口感/稳定性 | 醉茄根粉典型马尿/苦土腥味，标准化提取物经处理后掩味可达中等(E=6) |
| 市场/竞品 | 压力/焦虑+睾酮/运动表现叙事的草本适应原红海（KSM-66/Sensoril 大牌林立，亚马逊海量）；压力/睾酮 claim 双重踩 TikTok 红线 |
| 合规 | 草本/适应原(botanical/adaptogen)→ 命中 TikTok『所有草本+激素增强(睾酮)』红线；‘舌下=新摄入途径’亦可能触 NDIN（主封顶记 tiktok） |

## 三、产品评估

**六维打分依据**：校准锚点，复现 24。A=5：活性是 withanolides/withanosides 一团混合物，关键内酯 withaferin A 膜渗透极差(Peff 3.30e-7)、糖苷大分子(700+)更透不过，无可锚定的干净小分子→偏低。B=5：渗透/溶解度型+混合物伪需求，舌下绕过首过救不动一团大分子提取物。C=5：适应原慢性积累(压力/皮质醇需数周)、非急性即感→低。D=3：标准化提取物 300-600mg，单膜物理装不下。E=6：根味腥苦但标准化提取物经处理掩味可达中等。F=0：草本适应原+压力/睾酮叙事双踩 TikTok 红线，kill=tiktok 封顶≤45，实得 24。

**结论**：草本适应原一团 withanolides/withanosides 混合物，关键内酯渗透极差(Peff 3.3e-7)、糖苷大分子透不过、舌下救不动，剂量 300-600mg 装不下，叠草本+睾酮双 TikTok 红线 → 24 🔴 直接Pass（校准锚点）。
