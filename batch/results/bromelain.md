## 一、查证数据（带来源）

| 维度 | 数据 |
|---|---|
| 分子量 MW | 茎菠萝蛋白酶约 24-28 kDa(报道 23.8-37 kDa)，巯基(半胱氨酸)蛋白酶/硫醇内肽酶；远 >800 渗透死局 |
| logP/logD | 亲水球状蛋白(糖蛋白)，无固定 logP；被动跨膜不可能 |
| pKa/解离 | 多电荷蛋白，含活性位点 Cys；整体亲水 |
| 口服绝对BA% | 经典示踪研究估口服后约 40% 『可被吸收』、血浆峰 ~270 ng/mL 于 1h；但吸收的是以蛋白形态经特殊途径(可能 M 细胞/胞吞)进入，仍属大分子整体转运而非小分子被动跨膜——舌下黏膜面积小、无此通道，救不动 |
| BA低/高的机制(首过 vs 渗透) | 渗透型(伪需求)：24-28kDa 蛋白被动透不过黏膜，舌下/口腔膜对大分子完全救不动。即便口服有~40%『吸收』，那是肠道大面积+特殊摄取途径，舌下既无此面积也无此通道，绕不过跨膜障碍 → A=2、B=4 |
| 有效剂量 mg | 消化/抗炎常规 200-2000 mg(按 GDU/酶活计)，单次常 >500mg → 质量偏大、配合活性失活，单膜装载吃力，D=9 |
| 舌下/口腔黏膜人体证据 | 无人体舌下/buccal PK(有鼻腔递送临床前研究，恰说明黏膜递送是难题需专门设计)；活性蛋白酶含水成膜常温失活 |
| 口感/稳定性 | 略带菠萝/微涩，但根障是活性失活(stability)与渗透不可能，非口感 |
| 市场/竞品 | 消化酶/抗炎/术后消肿(常与槲皮素复配)赛道有量、可搭便车；但抗炎/消肿偏疾病 claim 红线、酶活标识混乱，给中(F=8) |
| 合规 | DSHEA 下作酶/消化辅助补剂存在；抗炎/消肿功效宣称偏红线；舌下=新途径另议，但根障是物理渗透 |

**来源**：https://pmc.ncbi.nlm.nih.gov/articles/PMC3312459/；https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9502857/；https://pmc.ncbi.nlm.nih.gov/articles/PMC9674142/；https://examine.com/supplements/bromelain/

**置信度**：high：MW 24-28kDa(半胱氨酸蛋白酶)、口服~40%吸收+血浆峰 270ng/mL@1h、消化/抗炎 200-2000mg 剂量均有来源支撑；渗透死局(MW>>800)+活性酶 stability 双重技术封死确定。所吸收为大分子整体转运经肠道特殊途径(非被动跨膜)，舌下不可复制此机制。

## 三、产品评估

**六维打分依据**：A=2：24-28kDa 半胱氨酸蛋白酶，远超 800，黏膜被动渗透物理不可能→渗透死局封顶≤50。B=4：渗透型伪需求，口服~40%『吸收』靠肠道大面积+特殊摄取途径(非小分子被动跨膜)，舌下无此面积/通道、救不动大分子。C=6：消化/抗炎属半急性-慢性，非急性即感。D=9：消化抗炎常 200-2000mg、单次常>500mg，质量偏大+需保活，单膜装载吃力。E=3：活性蛋白酶常温含水成膜无法存活(stability)，强制低 E。F=8：消化酶/抗炎赛道有量可搭便车，但抗炎消肿偏疾病 claim 红线+酶活标识乱，压分。kill=permeation cap50，实得 32。

**结论**：24-28kDa 半胱氨酸蛋白酶大分子，黏膜被动透不过(渗透死局，口服那~40%靠肠道特殊通道)、活性酶成膜即失活(stability)——舌下救不动，32 🔴。
