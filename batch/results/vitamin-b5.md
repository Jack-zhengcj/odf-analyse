【ODFanalyse 评估：维生素B5 泛酸 Pantothenic acid】  语境：补剂(supplement)

一、查证数据（带来源）
- **MW / logP / pKa**：泛酸 MW **219.23**（CID 6613）；XLogP3 = **-1.1**（强亲水，穿不过磷脂双层）；羧酸 pKa ~4.4 → 口腔 pH≈6.5 与生理 pH 下**高度解离为阴离子**，被动跨膜极差；强亲水易溶于水，游离酸为**吸湿性粘稠液体**，钙盐 1g/3mL。〔PubChem CID 6613；Wikipedia〕
- **口服 BA% 及机制**：口服**吸收良好**——膳食来源约 **50%**，合成泛酸/泛酸钙更高；机制为 **SMVT(SLC5A6)钠依赖主动转运**，高剂量(10-100mg)饱和后转**被动扩散**为主、约 **60% 经尿排出**(=已充分吸收)。属**【已满/饱和 + 渗透型】**，**非首过型** → 舌下绕过首过**无价值，救不动**。Tmax 数小时级，无急性体感。〔PMC4406285；PubMed 23578027〕
- **有效剂量**：维生素维持仅 **RDA 5mg**(装得下)，但**真实需求(TikTok=痤疮)用克级**：中度痤疮 **2.2 g/天**、重度囊肿型 **up to 10 g/天**(分4次)——远超单膜 API 上限(~10-50mg，纪录 62.5mg)。→ **触剂量一票否决**；而 5mg 维生素剂量则**无任何急性/BA 提升价值**。〔Drugs.com；Mayo Clinic；PubMed 24831048〕
- **口感 / 稳定性**：钙盐微苦可掩；主要工艺障碍是**吸湿性**(游离酸潮解、钙盐含水稳定性)——含水成膜偏脆/易吸潮。
- **市场 / 合规**：TikTok B5 热度集中在**痤疮/控油**(疾病-护肤 claim，限流/合规风险)与外用精华；口服竞品为胶囊/片，**无口溶膜竞品也无剂型不可替代性**；维生素维持版无急性场景、复购靠习惯。DSHEA 下泛酸钙合法，但**痤疮疗效宣称=疾病 claim，TikTok 限流红线**。〔Mayo；Healthline；TikTok〕

三、产品评估
- **卖点该押什么**：无可押 BA/吸收。泛酸口服 BA 已经够高(SMVT 主动转运+高剂量饱和)，舌下绝无"成倍救回"空间，押"更好吸收"即虚假宣称。维生素维持版本(5mg)能装进膜，但无急性体感、无可视频化功效，撕膜 ASMR / 无水便携救不了"没有差异化价值"。若硬要做，只能切纯仪式感日常维生素膜，但被 Natrol $0.07/片快溶片价格锚碾压。
- **第2层商业体检**：不进入(总分 < 70)。剂型横向对标上，胶囊/片在单位经济与剂量灵活性上完全碾压膜剂；B5 没有任何剂型不可替代性。
- **风险红线**：①**剂量一票否决**——TikTok 真实需求(痤疮)需 2.2-10 g/天，远超单膜 100mg 上限，物理装不进，D=2；②**合规**——痤疮疗效=疾病 claim，TikTok 限流；③**理化**——logP -1.1 强亲水羧酸阴离子，舌下渗透型救不动；④**吸湿稳定性**——含水成膜潮解风险。
- **一句话结论**：强亲水带电使 A 极低，口服 BA 经 SMVT 已充分吸收且高剂量饱和(渗透/已满型非首过)使 B 无可救——双双证伪舌下逻辑；而商业真实需求(痤疮)又要克级剂量，命中剂量一票否决——**渗透型伪需求叠加剂量否决，直接 Pass**（位于肌酸 29 / GABA 30 之下，与亲水高BA水溶维生素的伪需求定性一致）。
