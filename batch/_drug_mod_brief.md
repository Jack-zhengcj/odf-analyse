# 药品·分子修饰可行性(MF)叠加层 · Agent 作业卡

你给**已评技术分的药品(mode=drug)**补第 2 轴 **MF 分子修饰可行性 /100**。技术分(tech_moat)和 G 已存在、**不要动**。完整规则见 `references/drug-modification-model.md`，本卡是执行摘要。

## 核心心智（范式转换）
旧问题=「这药**原样**能不能舌下/口溶膜？」→ 不能就写死。
**新问题=「给定商业大奖 G，能不能用分子修饰/制剂工程把 ODF/口腔黏膜这条路做出来，多难、走哪条路、能不能拥有(FTO)？」**
药品天然难，但多数障碍可解。**v2 取向**：原生分子属性(大小/溶解)已**降权**(因为有修饰能改)，重点在「有没有现成解法+先例、多难、IP/FTO」。

## 每个药的步骤
1. `cat batch/results/<id>.json` 读：`key_data.BA_mechanism`(**障碍诊断,最关键**)、`MW`/`dose_mg`/`oral_BA`、`tech_moat`、`G`、`sellable`、`one_liner`。
2. 定 `barrier_type`（从 BA_mechanism 归类）：首过型 / 渗透-亲脂不足或带电小分子 / 渗透-大分子肽 / 渗透-蛋白单抗死局 / 剂量否决 / 已高BA无障碍。**障碍类型决定 MF1 与解法**。
3. 判 5 子分（满分见下，越高=越能/越值得把这条路做出来）：

| 子分 | 满分 | 要点 |
|---|---|---|
| **MF1 障碍残余**(原生属性已降权) | 20 | 首过型17-20 / 亲脂小分子渗透13-17 / 大分子肽9-14(修饰后松绑) / 剂量否决无增效路4-9 / 蛋白单抗死局0-5 |
| **MF2 工具箱适配+技术先例** | 30 | 已上市改良产品26-30 / 强文献专利类似物16-25 / 仅理论5-15 / 无路0-4。**点名工具箱策略**(盐·亲脂前药·离子对·促渗剂SNAC/C10·酶抑制·脂化PEG·环糊精·SEDDS纳米·订书肽·增效类似物) |
| **MF3 修饰难度**(易=高) | 20 | 盐/前药/重制剂505(b)(2)=15-20 / 促渗共制剂11-16 / NCE脂化·订书肽·增效类似物3-10 / 全新临床毒理0-5 |
| **MF4 IP/FTO 自由实施** | 15 | 路由开放/原专利到期/有规避路径11-15 / 原研牢占修饰路由(如Novo口服司美配方)0-5 |
| **MF5 路由临床价值**(去营销化) | 15 | 急救起效/避首过肝毒/儿科避吞咽/滥用威慑/可滴定=11-15 / 口服本就够改了无临床增益0-5 |

4. 定性字段：`--strategy`(点名解法,如"亲脂前药+环糊精"或"促渗SNAC+酶抑制"或"无需修饰直接舌下")、`--difficulty`(505b2重制剂/促渗共制剂/NCE脂化/NCE增效类似物/死局)、`--fto`(IP/FTO 一句话：路由是否被原研占住)。
5. **研究纪律**：每个药做 **1-3 次精准 WebSearch** 查：①该药有没有已上市/在研的舌下·含颊·口溶膜·口服增强(促渗/前药)产品 ②修饰先例文献/专利 ③FTO(原研是否占住改良路由)。这是药品轴的关键，别凭空判。
6. 调合并脚本(保留技术字段+G、确定性算矩阵,别手改JSON；G 自动取JSON已评值)：
```
python3 scripts/add_drug_mod.py <id> --MF1 .. --MF2 .. --MF3 .. --MF4 .. --MF5 .. \
   --barrier ".." --strategy ".." --difficulty ".." --fto ".." --one-liner ".."
```
（`--one-liner` 别用 `$` 符号，写"美元"）看回显 `MF分/矩阵` 是否合理。

## 决策矩阵：G(大奖,/20) × MF(/100)，G高线12 · MF高线60/中40
🟢攻坚首选(G≥12&MF≥60) · 🟡值得长攻(G≥12&MF40-59) · 🔴硬骨头暂搁(G≥12&MF<40) · ⚪能做不急(G<12&MF≥60) · ⚫放弃(其余)

## 校准锚点（对齐别飘）
- 硝酸甘油 G9 → MF96 ⚪(首过型,无需修饰,generic开放)
- 尼古丁 G18 → MF88 🟢(首过型,含片已上市)
- 睾酮 G16 → MF81 🟢(首过+亲脂,含颊Striant先例)
- **司美格鲁肽 G20 → MF58 🟡值得长攻**(大分子肽,促渗+脂化,口服Rybelsus先例,但FTO差Novo占位)— 已评,做参照
- 胰岛素 G18 → MF37 🔴硬骨头(蛋白死局,Oral-lyn数十年失败,但FTO反开放)
- 二甲双胍 G11 → MF26 ⚫(剂量否决+口服本就够,无路无价值,负对照)

## 纪律
- 只评 mode=drug；遇到 supplement 跳过(脚本会拒绝)。
- **不改**任何技术字段(A-G/tech_moat/key_data/sellable…)。
- MF1 别再为原生大小/溶解狠扣分——那是修饰要解决的；重点放 MF2(有没有解法+先例)/MF3(多难)/MF4(FTO)。
- 分数要能被锚点解释。每个药跑完脚本回显确认即可。
