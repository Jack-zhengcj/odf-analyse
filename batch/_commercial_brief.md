# 商业可行性叠加层 · Agent 作业卡

你给**已评完技术分的补剂**补上**第 2 轴：商业可行性 commercial /100**。技术分（tech_moat /80）已存在、**不要动**。完整规则见 `references/commercial-model.md`，本卡是执行摘要。

## 核心心智
技术分答「舌下/口溶膜科学上值不值」；商业轴答「作为美国 TikTok DTC 产品**卖不卖得动**」。两轴正交。**生物利用度低 ≠ 卖不动**：谷胱甘肽口服几乎不吸收却被营销到 ~$1 亿/年。你的任务是诚实量化「能卖多少」，并用 `efficacy_basis` 当护栏区分「真效力错格式」与「纯讲故事」。

## 每个成分的步骤
1. `cat batch/results/<id>.json` 读已有数据：`tech_moat`、`key_data`（尤其 `market` 竞品 / `regulatory` 合规 / `dose_mg` 剂量 / `taste`）、`kill`、`name`、`one_liner`。
2. 结合你的市场常识（必要时 1-2 次精准 WebSearch 查赛道规模/竞品/TikTok 趋势，别过度查）判 5 个子分：

| 子分 | 满分 | 判分要点 |
|---|---|---|
| **M1 需求规模&刚性** | 25 | 常青大刚需(睡眠/减重/美白美容/能量/肠道/抗衰/性功能/情绪压力)=20-25；小众功能(单一酶/微量元素/单关节成分)=5-12 |
| **M2 叙事/趋势/病毒** | 25 | 渴望故事+趋势套利+可拍前后对比+网红契合=20-25(玻璃肌/Ozempic平替/排毒/肠脑/cortisol/sleepmaxxing)；无故事不可视化=5-12。**越玄越好讲,常与科学反比** |
| **M3 剂型即卖点** | 20 | 剂型本身驱动购买(撕膜ASMR/贴片仪式/无水便携/无药丸/礼盒)+最佳剂型契合=14-20；剂型无新奇=4-9 |
| **M4 claim&渠道** | 15 | 能在某渠道合规营销+多渠道=11-15；触限流扣分**不清零**=6-10；**成分违法/被FDA剔除(NMN-美国/长春西汀/BMPEA)或硬疾病claim=2-6** |
| **M5 单位经济&复购** | 15 | 高毛利撑溢价+低COGS+高频复购=11-15；被价格锚碾压($0.07/片)/低频/克级贵原料=3-8 |

3. 定 3 个定性字段：
   - `--efficacy` ∈ {真实证据(最佳剂型下有RCT/明确机制,如肌酸/Omega-3/纤维/益生菌-肠道/褪黑素) | 弱证据(混杂/替代终点,如口服胶原/谷胱甘肽/姜黄) | 纯叙事(基本无可信系统证据,如海苔/多数透皮贴/绿粉万能宣称)}
   - `--best-format`：ODF / gummy / patch / powder或stick / shot或液体 / capsule（**放宽到全剂型**：ODF装不下/吸不收就标真正成就这门生意的剂型，如肌酸→powder、胶原→gummy、益生菌→capsule。可加「(非ODF)」注明）
   - `--redline` ∈ {none | regulatory(成分违法/被剔除) | safety(UL超标/安全红线如碘/育亨宾)}
   - `--risk`：逗号分隔，取自 {高退款无体感 / FTC-claim / 平台封号 / 成分合规红线 / 品牌扒皮 / 价格锚碾压}
4. 写一句 `--one-liner`：商业视角的判词（为什么卖得动/卖不动、卖什么叙事、最大风险、该换什么剂型）。
5. **调用合并脚本**（它保留全部技术字段、确定性算出象限/档位/原型，别手改 JSON）：
   ⚠️ **`--one-liner`/`--risk` 里绝对不要用 `$` 符号**（bash 会把 `$1`/`$0` 当变量吞掉，导致 `$100M`→`00M`、`$0.07`→乱码）。写「美元/USD」：如「约1亿美元」「100M美元级」「0.07美元/片」「20亿美元赛道」。
```
python3 scripts/add_commercial.py <id> --M1 .. --M2 .. --M3 .. --M4 .. --M5 .. \
   --efficacy 弱证据 --best-format "shot/泡腾" --redline none \
   --risk "FTC-claim,高退款无体感" --one-liner "……"
```
脚本会回显 `commercial 分 / 四象限 / go档位 / 原型`。确认落档合理即完成该成分。
